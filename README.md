# Algorithm Explorer – Smart Backpack Project

## About the Project
Algorithm Explorer is a web-based project that demonstrates how different algorithms solve the Smart Backpack (0/1 Knapsack) problem.

The user enters a backpack capacity and a list of items with their weights and values. The application compares different algorithms to find the best combination of items.

## Real-World Application
This project is useful for packing bags, selecting products within a budget, cargo loading, and resource management.

## Algorithms Used
1. **Brute Force:** Checks all possible combinations to find the best solution.
2. **Greedy Algorithm:** Selects items based on their value-to-weight ratio.
3. **Dynamic Programming:** Uses a table to find an optimal solution.
4. **Backtracking:** Explores possible combinations and removes unsuitable choices.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Features
- Enter backpack capacity.
- Add items with weights and values.
- Compare four algorithms.
- Display selected items and total value.
- Understand algorithm performance.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter the backpack capacity and item details.
5. Run the algorithms and compare their results.

## Conclusion
This project helps students understand how different algorithms solve the same real-world problem and compare their efficiency.
